# 構文辞書

英語の重要構文 **120項目** を、辞書アプリのように引けるウェブアプリです。
ビルド不要・依存ゼロ。`index.html` をブラウザで開くだけで動きます。

```
git clone <this repo>
cd pattern-list
open index.html      # Windows なら start index.html
```

## 使い方

### 検索欄（最上部に固定）

入力するそばから候補が絞り込まれます（インクリメンタル検索）。
一致した箇所は見出し・意味・例文のどこであっても黄色くハイライトされ、
先頭の候補の語釈が右側（スマホでは下からせり上がるシート）に自動で表示されます。

引ける切り口は次のとおりです。

| 入力例 | 引っかかるもの |
|---|---|
| `too to` | 構文の見出し（英語） |
| `せずにはいられない` | 日本語の意味 |
| `仮定法` `倒置` | カテゴリ・文法用語 |
| `クジラ` | 関連キーワード・ポイント欄 |
| `whale` | 例文の中身 |

- **スペース区切りは AND 検索**です（`no more than` は3語すべてを含む項目）。
- 全角／半角、大文字／小文字、カタカナ／ひらがなは区別しません（`ＴＯＯ` でも `too` が出ます）。

### 並び順

| 状態 | 並び |
|---|---|
| 未入力 | 文法カテゴリ順（不定詞 → 動名詞 → 分詞 → 関係詞 → 比較 → 仮定法 → 接続詞・副詞節 → 強調・倒置・省略 → 助動詞 → 名詞構文・無生物主語）。各カテゴリ内は学習順 |
| 検索中 | 関連度順。見出しの完全一致 → 前方一致 → 部分一致 → 意味 → キーワード → 例文、の順に点が高くなります。同点なら見出しが短いもの、次に 基本 → 標準 → 発展 |

### そのほか

- **カテゴリチップ**で範囲を絞ってから検索できます。
- 語釈の**関連キーワード**をタップするとその語で引き直します。
- **あわせて引く**から関連構文へ飛べます。
- 表示中の項目は URL のハッシュ（例 `index.html#cmp-06`）に残るので、ブックマークや共有ができます。
- OS のダークモード設定に追従します。

### キーボード操作（PC）

| キー | 動作 |
|---|---|
| `/` または `Ctrl`/`⌘` + `K` | 検索欄へ移動 |
| `↑` `↓` | 候補を選ぶ（語釈も連動） |
| `Enter` | 選んだ項目の語釈を確定表示 |
| `Esc` | 検索欄を消す／シートを閉じる |

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目（ライト／ダーク両対応、スマホ対応） |
| `data.js` | 見出しデータ 120項目 |
| `app.js` | 検索・並べ替え・ハイライト・描画 |

## 項目を増やすには

`data.js` の `ENTRIES` に追記するだけです。検索・並び替え・関連表示は自動で反映されます。

```js
{
  id: "inf-17",                      // 一意なID（カテゴリ略号 + 連番）
  pattern: "be about to do",         // 見出し（検索の主キー）
  jp: "まさに…しようとしている",        // 意味
  cat: "不定詞",                      // CATEGORIES のいずれか
  level: "標準",                      // 基本 / 標準 / 発展
  ex: [
    { en: "He was about to leave.", ja: "彼はまさに出かけようとしていた。" }
  ],
  note: "近い未来を表す。be going to より切迫している。",
  keys: ["近接未来", "be going to"]   // 表示されないが検索対象になる別名
}
```

`cat` に新しいカテゴリ名を使うときは、`data.js` 冒頭の `CATEGORIES` にも
表示したい順番で追加してください（この配列の順序が未入力時の並び順になります）。

文字列はダブルクォートで囲み、文字列の中にダブルクォートは入れないでください
（英文中のアポストロフィも避け、`do not` のように書き下しています）。
